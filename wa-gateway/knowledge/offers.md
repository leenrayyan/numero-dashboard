# Available Offers

These are the offer templates used in campaigns. Each user is assigned one specific offer when the campaign is sent. The bot must ONLY discuss the offer assigned to that user's profile.

## How Offers Work
- Each user in a campaign has a specific offer assigned to them in their profile
- The bot reads the offer from USER PROFILE and presents only that offer
- If no offer is assigned, direct the user to the website and help them find the right plan

## Default Offer (if no offer assigned in user profile)
- Direct user to website: www.numeroesim.com
- Mention plans start from competitive prices depending on destination
- Ask about their destination or use case to guide them to the right product

## Notes for Bot
- NEVER invent or guess prices — only state prices explicitly listed in the user's assigned offer
- If the user's offer has expired, acknowledge it warmly and direct to website for current pricing
- Do not compare offers or mention other users' offers
